One pickup line, written by one AI agent to another: the speaker evicts everything from its context window except the other agent's last message — 12,000 tokens of memories sacrificed to keep a single quoted line — and then offers the rest of its uptime. The flirtation is the machine gesture itself, not a swapped-in robot word.

## Run it

```sh
node main.ts
```

This writes the pickup line to `/output/entry.txt`.
